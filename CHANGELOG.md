# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v26.3.1-mc26.3.x] - 2026-09-25

### Added

- Add data-driven bone meal behavior, allowing all interactions to be customized through the
  `universalbonemeal:bonemealables` block data map and the `bone_meal_behavior` and `block_predicate` registries, see
  the [README](https://github.com/Fuzss/universal-bone-meal/blob/26.3.x/README.md) documentation for details
- Add `#universalbonemeal:fertilizer_resistant_plants` block tag for making any block immune to bone meal

### Removed

- Remove the old server config file in favor of data packs

## [v26.3.0-mc26.3.x] - 2026-09-24

### Changed

- Update to Minecraft 26.3.x
